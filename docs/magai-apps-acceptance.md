# magai 小智 App 扩展验收清单

> 版本:v1.1 | 目标板:magai-wifi(ESP32-S3, 240x280 NV303b) | 变体同步:magai-ml307(仅编译验证)
> 角色:验收工程师(magai-acceptance)按本清单逐项验收,总工程师(magai-chief-engineer)复核
> v1.1 新增:第八节 触摸屏交互 / 第九节 IP 定位与 UI 设计验收

## 一、基线功能(不得回归)

- [ ] 开机 60s 内进入聊天界面,状态栏显示网络图标与时间
- [ ] 聊天态按住触摸键(GPIO0)说话,松开停止,语音对话正常
- [ ] 聊天态 vol+/vol- 单击调节音量,屏显通知正确
- [ ] WS2812 灯效随设备状态变化(听/说)

## 二、App 启动器(M1)

- [ ] 聊天态长按 vol+ 进入启动器,菜单 4 项:聊天助手/天气时钟/2048/在线音乐
- [ ] vol+ 短按向上、vol- 短按向下循环导航,选中项高亮
- [ ] 触摸键短按进入选中项;选中"聊天助手"回聊天界面
- [ ] 启动器内长按触摸键返回聊天
- [ ] 语音"打开启动器"类指令可达(经 self.app.launch)

## 三、天气时钟(M2)

- [ ] 进入即显示大号时钟(SNTP 同步后与手机对时,误差<2s)与日期
- [ ] 天气区 30s 内显示:图标/天气文本/温度/湿度/城市(默认北京)
- [ ] 时间同步前显示 "--:--",不崩溃
- [ ] 语音切换城市(如"上海")后城市名与天气刷新
- [ ] 每 30 分钟自动刷新(可缩短验证:串口观察 Weather: 日志)

## 四、2048(M2)

- [ ] 新游戏出现 2 个初始方块
- [ ] vol+ 短按=上、vol+ 长按=右、vol- 短按=下、vol- 长按=左,滑动方向正确
- [ ] 相同数字碰撞合并,分数累加正确(2+2=4 记 4 分)
- [ ] 空格不足时新方块只在空位生成
- [ ] 死局时显示"游戏结束"遮罩,触摸键重开
- [ ] 最佳分数跨重启保留(NVS)
- [ ] 长按触摸键退出回启动器

## 五、在线音乐(M2)

- [ ] 进入自动播放预置电台 1,状态显示"播放中"
- [ ] 扬声器有声音,无持续爆音/杂音(允许首 2s 缓冲卡顿)
- [ ] vol+/- 短按切台(4 个台循环),显示台名
- [ ] 触摸键短按暂停/继续,状态正确
- [ ] 长按触摸键退出后音乐停止,回聊天语音正常(音频通道无残留占用)
- [ ] 聊天说话时音乐不与其叠加(互斥生效)

## 六、语音 MCP 工具(M1/M2)

- [ ] "打开2048"→ self.app.launch(name=2048) 生效
- [ ] "打开天气时钟"/"打开音乐"同理
- [ ] "回到聊天"→ self.app.launch(name=chat) 生效
- [ ] "列出应用"→ self.app.list 返回 JSON

## 七、稳定性

- [ ] 连续操作(切 App/玩游戏/切台)10 分钟无死机、无看门狗复位
- [ ] 串口每 10s 的 heap 统计无持续下降(泄漏)
- [ ] magai-ml307 变体 `idf.py -B build-ml307 build` 编译通过

## 八、触摸屏交互(v1.1 新增)

- [ ] 启动日志出现 `Touch IC detected at 0x??`(探测到触摸芯片;若 `No touch IC found` 则触摸不可用,其余项跳过)
- [ ] 启动器:直接点磁贴进入对应 App,点「返回聊天」回聊天
- [ ] 2048:手指上下左右滑动,方块按滑动方向移动
- [ ] 音乐:点 ⏮/⏭ 切台、⏸/▶ 暂停恢复,按钮热区足够大(56x44)
- [ ] 触摸与实体键可混用,不冲突

## 九、IP 定位与 UI 设计(v1.1 新增)

- [ ] 启动后 1 分钟内天气时钟城市自动变为当前 IP 所在城市(串口 `IpLocator: IP located city: XXX`)
- [ ] 未手动设置时每次重启都会重新定位;手动设置(语音)后不再被覆盖
- [ ] 语音「把城市改成上海」→ self.weather.set_city 生效,城市名与天气刷新
- [ ] UI 符合设计规范(docs/ui/DESIGN.md):深色背景 #1A1B25、卡片圆角、磁贴带图标、选中态蓝色边框
- [ ] 天气时钟:大号时钟+日期城市一行+天气卡片(图标/温度/详情)
- [ ] 2048:分数卡/最佳卡+棋盘居中,瓦片配色符合色板
- [ ] 音乐:唱片圆形区+台名+状态+三按钮控制条
